# Ravi Ranjan · Portfolio

A one-page portfolio in plain HTML, CSS and JavaScript: no build step, no frameworks.

## Open it

Double-click `index.html`. Skill icons come from skillicons.dev, so they need an internet connection.

## Files

- `index.html`: all the content (hero, about, skills, projects, education, contact)
- `css/style.css`: styles, light and dark themes, animations
- `js/main.js`: theme switch, mobile menu, typing line, scroll reveal, counters, copy email
- `assets/`: profile photo and the animated Mentora showcase

## Publish it free with GitHub Pages

1. Create a public repository named `RaviRanjan2069.github.io`.
2. Upload these files to it (keep the folders).
3. In the repository: Settings → Pages → Source: Deploy from a branch → `main` / root → Save.
4. After a minute the site is at https://raviranjan2069.github.io
