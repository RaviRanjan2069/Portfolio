# Ravi Ranjan · Portfolio

A one-page portfolio in plain HTML, CSS and JavaScript: no build step, no frameworks.

## Open it

Double-click `index.html`. Skill icons (skillicons.dev) and fonts (Google Fonts) need an internet connection.

## Files

- `index.html`: all the content (hero, about, skills, projects, education, contact)
- `css/style.css`: styles, light and dark themes, animations
- `js/main.js`: theme switch, mobile menu, typing line, heading and scroll reveals, counters, nav pill, pointer effects (spotlight, tilt, magnetic buttons), hero parallax, copy email
- `assets/`: profile photo and the animated Mentora showcase

## Live site

https://raviranjan2069.github.io/Portfolio/ (GitHub Pages, from the `main` branch of this repository).
Push changes to `main` and the site updates within a minute or two.
